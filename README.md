# Tempus — Luxury Watch Store

A modern and responsive luxury watch e-commerce frontend template built with React and Vite.

## Website Preview

![Tempus Website Preview](screenshots/tempus-preview.png)

**Live Demo:** https://tempus-watch-store-phi.vercel.app/

## Features

- Modern, responsive homepage
- Watch categories and product collection
- Product search, filtering and sorting
- Interactive watch customizer
- Live price updates
- Reusable React components
- Mobile-friendly design

## Built With

- React
- Vite
- JavaScript
- Bootstrap 5
- CSS
- React Router

## Installation

```bash
git clone https://github.com/Rabina-Vishwakarma/tempus-watch-store.git
cd tempus-watch-store
npm install
npm run dev
```

For production:

```bash
npm run build
```

## Customization

- `src/data/site.js` — Website details and navigation
- `src/data/watches.js` — Watch products and information
- `public/images/` — Website images
- `src/styles/style.css` — Website styling

## Note

This is a frontend demo template. It does not include backend services, checkout, payment processing or order management. About, Blog and Contact pages are currently placeholders.
